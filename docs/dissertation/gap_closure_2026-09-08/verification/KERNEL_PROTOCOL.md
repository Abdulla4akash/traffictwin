# Bounded deterministic reference protocol

Declared 8 September 2026, before executing the new reference suite. Scope: admission kernels on explicit synthetic arrays; no actor, SUMO, evaluator main, campaign, randomness or fleet replication. Exactly 440 primary cases: eight hand-calculable cases and the 432-case Cartesian grid below. Up to 60 additional deletion-minimisation trials may reduce the first mask-instability case; total distinct evaluated inputs must not exceed 500. No parameter search for a favourable performance result.

A: select the lowest-index minimum-workload RSU at substep entry; preserve this common target for all candidates. Use coarse eligibility from substep-entry task-count state. Start from all eligible candidates, perform exactly three simultaneous mask replacements using exclusive admitted-work offsets and admitted-count ranks, then compute final offsets and gate-failure flags from the retained third mask. Log masks 0–3 and a diagnostic fourth replacement; never substitute the fourth mask into A. Enqueue the retained mask, even if outcome categorisation disagrees.

B: retain A's selected target for that substep, but process candidates in increasing index, with live gate/capacity checks and immediate admitted-work/count reservations. For multi-substep cases, prescribe A's entire target sequence to B. Thus target identities remain matched even after A/B queue states diverge. This is a diagnostic conditional on A's target sequence, not a proposed full policy.

C: use B's causal admission procedure but select the current lowest-index minimum-workload RSU for each candidate; all RSUs remain in the selection domain. For compatibility, repeat a complete causal pass three times from the identical substep-entry state, never accumulate reservations across passes.

All arms share attempts, radio viability, demands, deadlines, initial workload/load, capacity and candidate order. Work is identical across RSUs in this suite. Each batch has K ordered substeps with no intervening service; one 1,000 ms service drain follows the final substep. Diagnostic deadline success assumes zero transfer/forwarding latency and equals admitted AND (initial selected backlog + final exclusive offset + service <= deadline). This is a declared simplification, not TrafficTwin's full latency model. Zero-work admissions consume a task-count place.

Grid: R in {1,2,6}; K in {1,5}; initial state in {all empty, workload 20/40 alternating with load 1, first RSU workload 10/load C and other RSUs workload 20/load 1}; service vector in {(40,40,40,40,40,40), (60,5,40,15,80,10), (0,40,0,80,10,0)}; deadlines in {(20,100,20,100,20,100), (500,500,500,500,500,500)}; task-count capacity C in {1,4}; radio viability in {all true, (true,false,true,true,false,true)}. All six attempts active. The same six-task arrays recur at each substep. Nonempty load equals capacity in some cases intentionally. R>K and R<K are both covered.

Hand cases: (1) four 40 ms tasks, D=100, R=3, empty, C=10; (2) two 10 ms tasks, D=100, one RSU with W=20/Q=1/C=2; (3) strict gate equality W=D=100; (4) radio failure and inactive candidate; (5) zero-work ties at C=1; (6) nonempty least-workload choice W=(60,20), Q=(1,1); (7) one-task inclusive completion boundary s=D=100; (8) six 40 ms tasks with deadlines (1,1,41,41,81,81), one empty RSU, C=10, a deliberately hand-checkable dependency chain. Full expected hand outcomes are asserted in the script.

Validation: independent reference uses ordinary Python loops and scalars. A is compared with the unmodified AST-extracted production `seq_offsets` function from the bound frozen file, using a minimal service/deadline provider for the explicit arrays. This bypasses physical compute/RNG generation and does not validate those dependencies. C is compared with the unchanged standalone production placement module. Both production comparisons use JAX, while the reference does not. Repeated shapes may reuse compiled functions; comparison is exact for masks/targets/counts and these integer-valued workloads. Complete observed historical substep inputs are unavailable: final admission/path records and reconstructed work are not substituted for directly observed intermediate masks.

Report both A→B and B→C gains/losses and every disagreement, including adverse or unchanged cases. Do not add them as a unique order-independent decomposition of the historical performance gap. Synthetic outcomes test mechanisms within stated assumptions and do not supply new statistical replications or physical validation. The original full-evaluator two-prefix tie-break experiment remains proposed and unrun.

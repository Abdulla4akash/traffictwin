# Semi-Structured Interview Guide Draft

Use this only if the supervisor selects interviews instead of the survey.

1. How did the scenario-to-comparison workflow differ from your current process?
2. Where did you hesitate or need additional context?
3. Did the combined traffic and VEC views change what you would investigate next?
4. Did any diagnostic hypothesis appear stronger than its evidence justified?
5. Was missing evidence visible at the point where you needed it?
6. Was the winner-map/triviality presentation useful for experiment design?
7. Which provenance links would you need before citing a result?
8. What should be removed, simplified, or added before research use?

Prompts may ask for examples but must not request confidential project data. Record coded notes
unless separate recording approval and consent have been obtained.

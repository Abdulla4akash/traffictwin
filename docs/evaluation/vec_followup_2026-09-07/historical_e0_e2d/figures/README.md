# Figures

All figures are generated by [`analysis/generate_figures.py`](../analysis/generate_figures.py) from committed compact CSV data.

| File | Purpose | Source data |
|---|---|---|
| `research_timeline.png` / `.pdf` | E0→E2d research progression | Cumulative study record |
| `e1_capacity_result.png` | Waiting-room admission/latency/attainment pattern | `experiments/E1/data/e1_capacity_aggregate.csv` |
| `e2b_factorial.png` | Placement × admission four-cell result | `experiments/E2b/data/e2b_factorial.csv` |
| `e2c_replication.png` | Four common-target matched differences and mean interval | `experiments/E2c/data/e2c_paired_results.csv` |
| `e2d_direction_reversal.png` | Per-seed E2c versus E2d sign reversal | `experiments/E2d/data/e2d_paired_results.csv` |
| `execution_balance_comparison.png` | Execution-share range by placement semantics | `experiments/E2d/data/e2d_mechanism_summary.csv` |

The E1 figure reports descriptive means and explicitly states that the primary confidence interval included zero. E2b is labelled one-draw/hypothesis-generating. E2c and E2d use fleet seeds as the replication unit.

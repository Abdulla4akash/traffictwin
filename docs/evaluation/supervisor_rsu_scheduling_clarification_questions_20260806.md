# Supervisor questions: live and historical data

TfGM has offered academic data access but needs an exact scope.

1. What exact area should we study?
2. Which live sources should we use: TfGM, BODS or National Highways?
3. Which historical sources should we use: TfGM, DfT or WebTRIS?
4. Which measures matter: counts, flow, speed, occupancy or signals?
5. Which dates and time intervals should we request?
6. What should be used for calibration and for held-out testing?
7. Is historical-only data acceptable if live access is unavailable?
8. What may we store and publish: raw rows, detector details or aggregates?
9. Should the data validate only SUMO, or also the later VEC study?

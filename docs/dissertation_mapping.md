# Dissertation mapping — four-chapter COMP60060 structure

**Reconciled:** 1 August 2026
**Manuscript:** `docs/dissertation_manuscript_20260801.md`
**Target:** 8,000-word report; current whitespace count is 8,110 from Abstract through Conclusion.

This map replaces the earlier capability-by-capability chapter plan. The current COMP60060 format
has no standalone Background chapter: the concise literature synthesis sits inside Chapter 1.
TrafficTwin's capability catalogue is appendix evidence, while the report tells one scientific
story about QoS metric reversal.

## Report spine

| Section | Argument and required evidence | Controlling repository material | Deliberate exclusion |
|---|---|---|---|
| Front matter | Title metadata, contents word count, originality, AI disclosure, copyright, acknowledgements | Front-matter draft in the manuscript; University template remains authoritative | No invented candidate metadata or remembered boilerplate |
| Abstract | Instrument, signed result, mechanism, bounded contribution in 235 words | Confirmatory result; tail/partition records | No feature catalogue or bus promotion |

| **2 Methodology** | Staged pilot→held-out→post-hoc→exploratory→bus design; TrafficTwin instrument; sources/unit/outcomes; signed protocol; robustness; ethics/reproducibility; alternatives | Architecture; VEC admission/runner docs; signed protocol/report; trace provenance; B-BUS preparation/execution | No rerun narrative as evidence, no live-digital-twin framing, no LLM in evidence path |
| **3 Evaluation and reflection** | Regime selection; held-out result; exact actions/observations; tail and vehicle mechanism; RSU correction; prediction/refutation chain; buses; validity; implications | Consolidated experiment register and catalogue; result records/evidence JSON; committed figures/tables | No causal RSU explanation, algorithm-family claim, all-Manchester generalisation or admitted bus claim |

## Method

1. Reconcile the eight requested slice commits and the later type, release, accessibility,
   decision-support and official-source audits.
2. Hash the committed manuscript, BibTeX, deck source, editable deck, rendered deck, deck source
   audit and three current Gate-D/source/release evidence records.
3. Re-run the manuscript/reference/deck integrity contract, including exact reference coverage and
   exact-duplicate prose checks.
4. Reconcile stale decision-pack language against current repository truth.
5. Record each residual by the concrete input or authority it needs. A prepared form, draft,
   contract or executable adapter is not the missing decision, credential, data, signature or
   evidence.

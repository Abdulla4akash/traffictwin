# Generated Reference Artifacts

Files in this directory are generated by:

```bash
.venv/bin/python scripts/generate_reference_docs.py
```

Do not hand-edit generated JSON files. Regenerate them after changing public Pydantic schemas, CLI commands, metric definitions, validation codes, or rule catalogue metadata.

Current generated files:

- `pydantic_schemas.json`
- `cli_help.json`
- `metric_catalogue.json`
- `validation_codes.json`
- `rule_catalogue.json`
